## 🛠 Troubleshooting

### Export fails or crashes

```powershell
# Lower export quality
# Export settings > Quality = High (not Best)

# Check disk space
Get-PSDrive C | Select-Object Used,Free

# Disable hardware acceleration
# File > Preferences > Performance > Hardware acceleration = Off
```

### Playback laggy in timeline

```powershell
# Enable proxy editing
# File > Preferences > Performance > Proxy = On

# Reduce preview quality
# Playback > Preview Quality = Half or Quarter

# Close other apps
Get-Process | Where-Object {$_.WorkingSet -gt 500MB} | Stop-Process
```
